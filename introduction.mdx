MonoGame is a free, open-source implementation of Microsoft's discontinued XNA Framework, giving C# developers a battle-tested platform for shipping games across desktop, mobile, and console targets. Games like Celeste, Stardew Valley, and Streets of Rage 4 were all built with MonoGame.

## What is MonoGame?

MonoGame is a **framework**, not an engine. It gives you a thin, expressive layer over the platform's GPU, audio stack, and input system — without imposing a scene graph or a visual editor. You write C# code that calls `Initialize`, `LoadContent`, `Update`, and `Draw`, and MonoGame handles the platform differences for you.

## Supported Platforms

| Platform | Package |
|----------|---------|
| Windows (DirectX 10+) | `MonoGame.Framework.WindowsDX` |
| Windows / Linux / macOS (OpenGL) | `MonoGame.Framework.DesktopGL` |
| Android (API 23+) | `MonoGame.Framework.Android` |
| iOS / iPadOS 12.2+ | `MonoGame.Framework.iOS` |
| Consoles (PS4/PS5, Xbox, Switch) | Private — requires platform registration |

<Note>
Vulkan and DirectX 12 support is available in **preview** for the `3.8.5` development builds on supported platforms.
</Note>

## Quick Example

```csharp Game1.cs
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;

public class Game1 : Game
{
    private GraphicsDeviceManager _graphics;
    private SpriteBatch _spriteBatch;
    private Texture2D _logo;

    public Game1()
    {
        _graphics = new GraphicsDeviceManager(this);
        Content.RootDirectory = "Content";
        IsMouseVisible = true;
    }

    protected override void LoadContent()
    {
        _spriteBatch = new SpriteBatch(GraphicsDevice);
        _logo = Content.Load<Texture2D>("logo");
    }

    protected override void Draw(GameTime gameTime)
    {
        GraphicsDevice.Clear(Color.CornflowerBlue);

        _spriteBatch.Begin();
        _spriteBatch.Draw(_logo, Vector2.Zero, Color.White);
        _spriteBatch.End();

        base.Draw(gameTime);
    }
}
```
